---

## 🌟 What Is VidioAI?

VidioAI is an AI-powered video editing web application that aims to analyze uploaded videos, identify their most valuable highlights, and generate multiple short clips ready for download.

Whether you're a content creator, YouTuber, student, or video editor, VidioAI aims to simplify the process of finding great moments in long videos.

## ✨ Key Features

- 🎥 **Video Upload:** Upload a video for analysis and processing.
- 🧠 **AI-Based Highlight Detection:** Identify potentially interesting moments using visual, audio, and speech-related information.
- ✂️ **Smart Clip Generation:** Generate 3 or 5 highlight clips based on the selected option.
- ⏱️ **Dynamic Clip Duration:** Aim to adapt clip length to the source video and selected number of highlights.
- ⚡ **Video Compression:** Prepare videos for more efficient processing.
- 📥 **Downloadable Shorts:** Export generated clips for further editing or sharing.
- 🌐 **Web-Based Interface:** Access the editor through a browser.

*Note: Some AI capabilities are still under development and require further testing. Features described as planned or intended may not yet work completely.*

## 🔄 How VidioAI Works

1. **Upload:** The user uploads a video through the web interface.
2. **Prepare:** The backend prepares and compresses the video for analysis.
3. **Analyze:** The system examines video frames and available audio information.
4. **Select:** The highlight-selection logic identifies promising segments.
5. **Generate:** FFmpeg processes the selected segments into separate clips.
6. **Download:** The user can download the generated videos.
